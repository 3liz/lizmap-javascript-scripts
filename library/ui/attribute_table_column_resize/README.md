# Attribute table column resize

Lets the user resize the columns of the attribute tables by dragging the border of the headers.

* Drag the right border of a column header to change its width.
* Double click on the border to restore the original widths of the table.
* Widths are saved in the browser (localStorage), per repository, project and table.
* Truncated texts show the full content on mouse hover.
* Dragging a border does not sort the column.

Available for Lizmap Web Client:
* 3.9 (tested with 3.9.12)
